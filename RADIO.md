# The Smoke · Radio & Studio Inbox (v0.5.15 public beta candidate)

The radio has **six supplied direct-stream presets**. It is a listening dial, not a rebroadcasting service. Every user connects to a broadcaster's own stream on their own device; no music, DJ voice, recording or real station player is distributed inside The Smoke.

## Listening in the Blower and cars

Open the radio from the Blower, scene controls, or a vehicle's **Car radio** right-click action. Press **Listen** to opt in. Use local volume/mute or **Stop listening**. The driver sets the station for the vehicle; passengers may listen at their own volume. Personal Blower preset selection stays with the character, and a single local receiver prevents duplicate playback. Audio playback and availability depend on the third-party broadcaster.

## Player: message studio or request airtime

In the Blower / radio window, pick a station and open **Message the studio**. Type up to 500 characters and select one of:

- **Message studio (GM only)** — sends a roleplay message privately to the active GM's Studio Inbox. The GM may reply as a *fictional* station producer.
- **Request airtime** — proposes an announcement. Nothing is broadcast immediately; the GM must approve it. The GM may post it to *in-game chat* now, or schedule it as a prerecorded segment using the Banana Watch.

Every message and announcement is **fictional in-game activity only**. A player cannot access station websites, WhatsApp, email, phone contacts or external chats through the Smoke radio UI. The data sent by either player button stays within the Foundry game and **is never submitted to an actual broadcaster**.

## GM: preserve real contact tools + moderate the in-game inbox

Open the **Pirate Radio** window from the scene control, even without a character. The GM can still open **Real station contacts** and the **Edit presets** directory. All existing real contact links are GM-only; using one explicitly opens an external website or local app. The game never auto-submits a message.

The same GM radio window contains **GM Studio Inbox** for private player messages and airtime requests. Each queued request can be:

- **Reply privately**, visible only to GMs and the requesting user.
- **Broadcast now** — add a labelled, fictional studio announcement to the game's chat for all players, *not* to any real stream.
- **Queue broadcast**, with a 1–1440-minute Banana Watch delay. A connected GM automatically releases it when game time reaches that point, including after an 8-hour rest/time jump.
- **Decline** — close the request with a private fictional response.

Requests persist as private ChatMessages. Scheduled status is stored on the same record. A given request cannot be approved twice; previously completed recordings do not replay when Foundry reloads. The current implementation requires an active GM for moderation and the release of scheduled announcements, and it relies on the chat log being retained.

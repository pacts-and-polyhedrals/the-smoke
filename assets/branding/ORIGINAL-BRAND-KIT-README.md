# THE SMOKE — Original Website Emblem Branding Kit

Created by **Pacts & Polyhedrals**.

This is the **correct website-header emblem**: a thin mint diamond enclosing an angular line and circular endpoint, with a separate pink diamond at the right. It replaces the unrelated rounded-square concept from the previous pack. The emblem geometry is reauthored as SVG after inspecting the original header HTML/CSS and the supplied reference screenshot.

## Logos (`logos/`)

- `The-Smoke-Symbol-Transparent`: icon alone, transparent background
- `The-Smoke-Symbol-Dark`: same icon on midnight
- `The-Smoke-Symbol-One-Colour`: white/ivory single-colour emblem
- `The-Smoke-Full-Logo-Horizontal-Transparent`: emblem + THE SMOKE wordmark + studio credit
- `The-Smoke-Full-Logo-Horizontal-Dark`: dark-background version
- `The-Smoke-Wordmark-Only-Transparent`: title without emblem
- `The-Smoke-Full-Logo-Stacked-Transparent`: vertical lockup
- `The-Smoke-Corrected-Favicon`: header-based favicon replacing the old site's misaligned rounded-square icon

Each has an editable, resolution-independent **SVG** and a large **PNG** export. Logo PNGs are transparent unless stated otherwise. The SVG text remains editable; the PNG exports preserve the tested visual appearance across systems. You can open the SVGs in Inkscape, Illustrator, Figma, or modern browsers. The display typeface is Roboto Condensed (or a comparable condensed sans-serif fallback).

## Three separate branding graphics (`graphics/`)

1. `01-The-City-Is-The-Board-Landscape`: 16:9 website/YouTube/Discord banner, illustrative map motif.
2. `02-The-Chainring-Cycle-Poster`: portrait poster / print / vertical socials, bicycle and railway arches.
3. `03-The-Blower-Social-Square`: square promo for socials featuring the in-game phone interface.

All are individual **true vector SVGs** plus their own 2×-resolution PNGs. The illustrations are stylised artworks, not literal street maps or UI screenshots from Foundry. All copy is public-facing and spoiler-safe.

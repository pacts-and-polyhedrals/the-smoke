# The Smoke v0.5.12 — Drop & Paint, Rep milestones & live radio

**Release tag:** `v0.5.12`  
**ZIP asset:** `the-smoke-v0.5.12.zip`  
**Second asset:** `system.json`  
**Manifest:** `https://github.com/pacts-and-polyhedrals/the-smoke/releases/latest/download/system.json`

## Changes

**Street graffiti:** Place a paintable marker on an actual street. Smoke auto-names it by zone in sequence (e.g. Morning Lane 1, Morning Lane 2). Right-click a marker for Tag Surface; a nearby player with Spray Paint can spray a validated tag without the GM assigning it to the casual marker first. Existing mission-specific destinations still require their proper location evidence. New graffiti lettering is transparent vector art from appropriately licensed font outlines; quality depends on the Graft roll. The 42 tag commissions and their territory/rep integration are retained.

**Rep growth:** Additional milestone choice every three Rep levels through 33; the original stat/perk choices, every-third-level Growth roll and tier bonuses all remain. Options are Health, Guard, Hustle or cash. Historical characters may claim missed rewards with no XP or Rep rollback.

**Radio:** CodeSouth.FM added with a public direct streaming URL. Esencia Urbana added as a website-only preset, since no reliable direct audio endpoint was verified. GM-customised station lists migrate once and respect subsequent changes.

**Included:** Full system, maps, venue pack, characters, missions, police/chase fixes, physical mission cargo, clock conditions and v0.5.9 original Smoke branding.

## Forge / GitHub release

1. Back up your world and preferably test on a clone first.
2. Create new GitHub release at `https://github.com/pacts-and-polyhedrals/the-smoke/releases/new` with tag **v0.5.12**.
3. Upload **both** assets separately: `the-smoke-v0.5.12.zip` and `system.json`.
4. Publish as latest and update Smoke in Forge through your existing manifest URL.
5. Restart the Foundry server and test a player right-click, a Rep milestone, CodeSouth live audio and Esencia Urbana's website button.

Do not alter the manifest URL or rename the ZIP asset. Neither code nor artwork has been deployed to the live Forge world by this build.
